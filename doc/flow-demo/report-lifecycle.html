C业务规则与观察点

售后期保护（设计行为）
SALE_PROTECTION_DAYS = 7：订单完成后佣金保留 estimated，需 completedAt 满 7 天由每日 02:00 cron（confirmEligible）推进至 pending_reconciliation。演示中如实展示保护窗口（orders=0），未人工跳过。
订单状态机双轨（设计行为）
报告发布事务（reports.service.publish）直接将关联订单置 report_ready；物流轨 paid→shipped→pending_sampling 为可选轨。检测服务类订单以报告为准，实物发货用于盒码寄送场景。
素材合规拦截（设计行为）
含违禁词「诊断」的 compliance_talk 模板被合规校验拦截，无法生成渠道素材；其余模板正常生成且内容末尾自动附加渠道码。
商家对账单 = 收入行（设计行为）
merchant 主体对账单的行项目为 order_settlement（商家结算收入行），而非佣金行；佣金行出现在 partner（合伙人）主体对账单中。商家对账单金额 = 订单额 − 供应成本 − 平台服务费 − 佣金。
对账结清与佣金联动（本轮已修复）
原观察点「对账单结清不回写佣金明细」已升级为缺陷并修复：settle 事务联动账单内佣金明细 → settled，reopen 对称回退（详见附录 B BUG-3）。
问卷 UI 提交（排查结论：功能正常）
此前记录的「问卷 UI 提交未生效」经复验为自动化脚本选项索引错误（页面 3 个「其他」选项定位歧义），纯 UI 操作提交成功，前端必填校验与错误提示准确工作（详见附录 B BUG-5）。
