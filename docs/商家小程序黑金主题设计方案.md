# 百英诺 · 商家中心｜黑金主题设计方案

> 适用端：`apps/mini-b`（商家小程序 · 微信小程序 + H5 双端同源）
> 版本：v1.0 ｜ 状态：已进入开发 ｜ 关联文档：《商家小程序整体优化产品开发方案》《C端小程序商品与定价统一优化方案》

---

## 1. 背景与目标

商家端当前主色为品牌紫 `#6E5CFF`，整体是浅色卡片风格。业务侧希望面向经销商 / 门店老板呈现更强的"高端、专业、可托付"气质，因此设计一套**黑金主题**，并作为**默认主题**；同时必须保留切回原主题的入口，避免老用户视觉断层。

| 目标 | 说明 |
|---|---|
| 风格升级 | 以"曜石黑 + 香槟金"重塑商家端视觉，建立高端保健品渠道的品牌感知 |
| 不改业务 | 仅视觉层与主题机制改造，页面结构、字段、接口、交互流程零变更 |
| 双端一致 | 小程序与 H5 共用一套令牌与样式，不允许出现两端配色漂移 |
| 可回退 | 原主题完整保留，用户可随时一键切回，切换即时生效并持久化 |
| 可维护 | 颜色只允许出现在令牌层，页面不得写死色值 |

## 2. 主题风格定义

**主题名：曜石黑金（Obsidian Gold）**

| 维度 | 定义 |
|---|---|
| 关键词 | 克制、质感、专业、可信 |
| 底色 | 近黑曜石 `#08080A`，卡片 `#141217`，比纯黑略偏暖，避免 OLED 上的"死黑"与廉价感 |
| 主色 | 香槟金 `#D4AF37`，仅用于强调：主按钮、金额、选中态、关键描边 |
| 金的用法 | 面积不超过单屏 12%：细描边、竖条、数字、图标着色；不做大面积金色填充 |
| 材质 | 卡片 `1px` 金边（14% 透明度）+ 顶部 8% 白色高光渐变 + 深阴影 |
| 文字 | 暖白 `#F4EFE4` 为一级，`#B3A995` 二级，`#7C7466` 三级；不用纯白，避免黑底刺眼 |
| 圆角 | 卡片 14px、按钮 10px、标签 6px、弹层 20px（比原主题 +2~4px，强化"厚重感"） |
| 动效 | 切换主题 180ms 颜色过渡；按下态金边提亮 8%；不使用闪烁类高光 |

**关键取舍：金色按钮用深色字，不用白字。**
白字 `#FFFFFF` 在 `#D4AF37` 上的对比度仅约 **2.1:1**，不达 WCAG AA；深色字 `#14110A` 可达 **≈9.0:1**。因此主按钮统一为「金底 + 近黑字」，既合规也更像高端品牌的压印工艺。

### 3.3 对比度校验（黑金主题）

| 前景 / 背景 | 对比度 | 结论 |
|---|---|---|
| `#F4EFE4` / `#141217` | ≈ 15.8:1 | AAA |
| `#B3A995` / `#141217` | ≈ 7.9:1 | AAA（正文可用） |
| `#7C7466` / `#141217` | ≈ 3.6:1 | 仅用于辅助说明（≥18px 或非关键信息） |
| `#D4AF37` / `#08080A` | ≈ 9.2:1 | AAA |
| `#14110A` / `#D4AF37` | ≈ 9.0:1 | AAA（主按钮） |
| `#FFFFFF` / `#D4AF37` | ≈ 2.1:1 | ❌ 禁用（故改用深色字） |

## 4. 布局与栅格

结构不变，仅统一视觉参数：

- 页面内边距保持 `12px`，卡片间距 `8px`，区块间距 `16px`（沿用 4px 基数）。
- 卡片圆角 `10px → 14px`；卡片内边距 `12px → 14px`，缓解深色下的"拥挤感"。
- 区块标题：左侧 `3px` 高 `14px` 竖条改为**金色渐变**（`#F2D98D → #B8952B`），文字色一级暖白。
- 数字统一 `font-variant-numeric: tabular-nums`，金额、指标、毛利对齐不跳动。
- 深色下描边优先于阴影：卡片用 `1px` 金边表达层级，阴影退为辅助（黑底上阴影几乎不可见）。
- 底栏 `.b-tabbar` 改为半透明黑 + `backdrop-filter: blur(12px)`（H5 生效，小程序降级为不透明 `#0C0B0E`），顶部 `1px` 金边。

## 5. 图标风格

现有图标为 `Icon.tsx` 的**零依赖 SVG mask 线性图标**（`viewBox 24`、`stroke-width 1.8`、`currentColor` 着色），黑金主题不重绘图形，只统一「着色 + 底衬 + 尺寸」三件事：

| 规格 | 规则 |
|---|---|
| 线宽 | 保持 1.8px（mask 无法逐主题改线宽，重绘成本高且易失真） |
| 着色 | 底栏选中 = `--mall-primary`；未选中 = `--mall-text-tertiary`；业务图标 = 金色 `#D4AF37` |
| 底衬 | 图标外圈 `34×34`、圆角 `10px`、底色 `rgba(212,175,55,.14)`、`1px` 金边 `rgba(212,175,55,.22)` |
| 语义色 | 成功/警告/危险图标沿用语义色，但统一降到 14% 透明底 + 实色描边，避免黑底上过艳 |
| 徽标 | 数字角标改为金底黑字（原为红色底白字），仅"待办/未读"保留红色以维持警示性 |

## 7. 主题切换机制

### 7.1 令牌分层

```
palette（基础色板）
  → designTokens（语义令牌，classic 默认值）
  → themePacks（gold / classic 两套语义值，packages/shared/src/tokens.ts）
  → CSS 变量（apps/mini-b/src/app.scss 的 .theme-* 块）
  → 组件样式只引用 var(--mall-*)
```

### 7.2 运行时方案

| 环节 | 做法 |
|---|---|
| 默认值 | `DEFAULT_THEME = 'gold'`，无存储时使用黑金 |
| 持久化 | `Taro.setStorageSync('mall_b_theme', 'gold' \| 'classic')` |
| 生效方式 | 页面根容器挂 class：`.theme-gold` / `.theme-classic`，变量在其子树内级联覆盖 |
| 跨页同步 | 模块级 `Set<listener>` 订阅，切换后所有已挂载页面 `useTheme()` 立即重渲染 |
| H5 额外处理 | 同步 `document.documentElement` 的 class 与 `body` 背景，保证 NutUI 弹层（Portal 到 body）也跟随主题 |
| 小程序额外处理 | `Taro.setNavigationBarColor({ backgroundColor: '#08080A', frontColor: '#ffffff' })`；`page` 背景由根容器铺满 |
| 防闪烁 | 首帧 `useState(getTheme)` 同步读 storage，H5 在 `app.tsx` 模块级先写 `html` class |
| 回退 | 「我的 → 外观主题」弹层内选「经典蓝紫」，即时生效并持久化；无接口、无发版依赖 |

### 7.3 交互入口

「我的」页新增 **外观主题** 入口（`经营工具` 区块下方独立卡片）：显示当前主题名与色卡预览，点击拉起底部弹层，两张主题卡（黑金 / 经典）并排，选中态金色描边 + 勾选，切换即时生效并 `toast('已切换为黑金主题')`。

## 8. 双端适配要点

| 项 | 小程序 | H5 |
|---|---|---|
| 状态栏 / 导航栏 | `navigationBarBackgroundColor: #08080A` + `frontColor: #ffffff`；主题切换时动态设色 | 由 Taro 页面容器控制，`body` 背景同步为 `--mall-bg`，避免滚动露白 |
| 安全区 | 底栏 `env(safe-area-inset-bottom)` 保留 | 同左；弹层底部追加 `safe-area` padding |
| 毛玻璃 | 部分机型不支持，降级为不透明 `#0C0B0E` | 支持 `backdrop-filter` |
| 输入框 | 原生 input 需显式设 `color` 与 `placeholder-style` | CSS 变量直接生效 |
| 滚动条 | 无 | 加 `::-webkit-scrollbar` 深色细滚动条 |

## 11. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 深色下低对比文字 | 说明文字看不清 | 三级文字不低于 `#7C7466`，关键信息一律用一级/二级 |
| 金色大面积使用显廉价 | 品牌掉档 | 金色面积 ≤12%，仅描边/数字/按钮 |
| NutUI 弹层未跟随主题 | 白底弹窗刺眼 | H5 同步 `html` class；小程序弹层处于页面子树内，变量自然继承 |
| 小程序不支持 `backdrop-filter` | 底栏半透明失效 | 提供不透明降级底色 |
| 老用户不适应 | 使用阻力 | 「外观主题」入口常驻 + 经典主题完整保留 |

## 12. 后续可选增强（本期不做）

1. 跟随系统深色 / 浅色自动切换；
2. 主题色可自定义（金 / 玫瑰金 / 铂金三档）；
3. C 端小程序同步黑金（需独立评审，C 端偏消费场景，转化优先）；
4. 管理后台 `apps/admin` 深色模式（antd ConfigProvider algorithm 切换）。
