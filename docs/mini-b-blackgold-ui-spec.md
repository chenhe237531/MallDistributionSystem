# 商家端「曜石黑金」UI 优化设计方案

> 适用范围：`apps/mini-b`（Taro 单代码库，同时编译 H5 与微信小程序）
> 技术底座：`@mall/shared` 设计令牌 → `--mall-*` CSS 变量 → 页面只引用变量、不写死色值
> 版本：v1.0 ｜ 2026-10-27

---

## 一、设计目标与原则

1. **高端奢华、克制用金**：黑色承担 80% 画面面积，金色只做「点睛」（标题、价格、主按钮、选中态），避免大面积金色造成的廉价感与视觉疲劳。
2. **双端一致**：H5 与小程序出自同一份 Taro 代码与同一份变量表，差异只体现在环境适配层（导航栏、弹层 Portal、安全区），不允许出现端专属色值。
3. **可读性优先**：深底金字必须满足 WCAG 对比度要求（正文 ≥ 4.5:1，大标题/图标 ≥ 3:1），本文所有推荐色值均已校验（见附录 A）。
4. **层级即奢华**：通过 4 级背景灰阶 + 3 级文字灰阶 + 1 级金色，建立清晰的信息层级，而不是靠堆砌装饰。

## 二、配色体系（色值规范）

### 2.1 黑金面积配比

| 层级 | 角色 | 占比 | 说明 |
| --- | --- | --- | --- |
| 深黑底 | 页面背景、导航栏 | ~70% | 画面基调，纯黑过死，用带暖调的炭黑 |
| 深色容器 | 卡片、列表项、弹层 | ~15% | 与底色拉开微弱明度差，靠边框而非投影分层 |
| 中性灰 | 正文、次级信息、默认图标 | ~10% | 暖灰系，避免冷灰在黑底上发蓝 |
| 金色 | 标题、价格、主按钮、选中态 | ~5% | 严格控制在点缀面积 |

### 2.2 背景色阶（深色）

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--mall-bg` | `#08080A` | 页面根背景、小程序窗口底色、导航栏底色 |
| `--mall-card` | `#141217` | 一级卡片容器（商品卡、信息卡） |
| `--mall-surface-2` | `#1B181F` | 二级浮层（弹窗、下拉、底部动作栏）、列表项按压态 |
| `--mall-surface-3`（建议新增） | `#242028` | 输入框填充、标签底色、表格行 hover |
| `--mall-nav-bg` | `#08080A` | 导航栏（与页面背景一体，靠底部分隔线分层） |

> 规则：相邻层级明度差保持在 6%–10%，**禁止出现 3 层以上嵌套卡片**；深色下不用投影分层，用「明度差 + 1px 边框」。

### 2.3 金色系

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--mall-primary` | `#D4AF37` | 香槟金主色：选中态、主按钮、图标高亮 |
| `--mall-primary-hover` | `#E3C173` | 浅金：H5 hover、渐变亮端 |
| `--mall-primary-pressed` | `#B8952B` | 哑金/深金：按压态、渐变暗端 |
| `--mall-primary-light` | `rgba(212,175,55,0.14)` | 金色弱底：选中标签底、图标背景圆 |
| `--mall-primary-light-pressed` | `rgba(212,175,55,0.22)` | 金色弱底按压 |
| `--mall-color-gold` | `#D4AF37` | 装饰性金（分隔线、角标、徽章描边） |
| `--mall-color-price` | `#F0C86A` | 价格专用亮金（比主色亮一档，黑底上更醒目） |
| 金色渐变（建议新增） | `linear-gradient(135deg,#E3C173 0%,#D4AF37 45%,#B8952B 100%)` | 主按钮、会员卡、核心 CTA |

> 金色使用纪律：单屏金色元素 ≤ 3 处（不含正文内价格）；装饰金线/金框透明度 ≤ 0.35；禁用荧光金、亮黄金（#FFD700 类）——在黑底上刺眼且偏"促销感"。

### 2.4 文字颜色层级

| 层级 | 令牌 | 色值 | 黑底对比度 | 用途 |
| --- | --- | --- | --- | --- |
| 一级标题 | `--mall-text` | `#F4EFE4` 暖白 | ≈17:1（AAA） | 页面标题、卡片标题、核心数字 |
| 二级正文 | `--mall-text-secondary` | `#B3A995` 暖浅灰 | ≈8.6:1（AAA） | 正文、描述、列表次要信息 |
| 三级辅助 | `--mall-text-tertiary` | `#7C7466` 暖中灰 | ≈4.3:1（AA·大字号） | 占位符、时间、辅助说明（限 ≥12px 或非关键信息） |
| 金色标题 | `--mall-primary` | `#D4AF37` | ≈9.4:1（AAA） | 板块标题、强调词、掌柜昵称等身份性文字 |
| 价格 | `--mall-color-price` | `#F0C86A` | ≈10.9:1（AAA） | 所有金额数字 |
| 反色文字 | `--mall-on-primary` | `#14110A` | 金底上 ≈9.1:1（AAA） | 金色填充按钮上的文字 |

> 规范：**金色不用于正文**（≥14px 连续阅读文字一律暖白/暖灰）；金色标题字号 ≤ 20px 时需加 `font-weight:600` 保证笔画识别度。

### 2.5 边框与分隔线

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--mall-border` | `#2F2A22` | 卡片边框、输入框边框（暖调深灰） |
| `--mall-border-light` | `#221E18` | 列表分隔线、区块分隔 |
| `--mall-card-border` | `rgba(212,175,55,0.14)` | 重点卡片的金线描边（会员卡、价格卡） |

### 2.6 功能色（深色适配版）

深色背景下功能色需提高明度、降低饱和，避免"霓虹感"：

| 语义 | 色值 | 弱底 |
| --- | --- | --- |
| 成功 `--mall-success` | `#3FBF7F` | `rgba(63,191,127,0.14)` |
| 警告 `--mall-warning` | `#E8A33D` | `rgba(232,163,61,0.14)` |
| 危险 `--mall-danger` | `#E4685C` | `rgba(228,104,92,0.14)` |
| 信息/链接（建议新增） | `#8FA8C8` 灰蓝金调 | `rgba(143,168,200,0.14)` |

## 三、界面优化规范

### 3.1 页面背景

- 根背景恒为 `#08080A`；H5 端需同步 `html/body` 背景（现有 `applyEnv()` 已处理，保留），小程序端同步 `setBackgroundColor` 窗口底色，避免下拉露白。
- 首屏 Hero 区使用深色渐变 `--mall-hero-grad`：`linear-gradient(135deg,#1A1509 0%,#241B0B 55%,#3A2A0E 100%)`（黑→深金棕），营造"暗处鎏金"感；渐变上叠加的金色装饰纹理透明度 ≤ 0.08。
- Banner 渐变 `--mall-banner-grad`：`linear-gradient(120deg,#141109 0%,#33270F 100%)`。

### 3.2 卡片容器

| 属性 | 规范 |
| --- | --- |
| 背景 | `var(--mall-card)` #141217 |
| 圆角 | 12px（`radiusLg`），小标签 8px |
| 边框 | 1px `var(--mall-border-light)`；重点卡片用 1px `var(--mall-card-border)` 金线 |
| 阴影 | `--mall-shadow: 0 6px 20px rgba(0,0,0,0.55)`（仅浮层使用，列表卡不用） |
| 金色辉光 | `--mall-glow: 0 0 20px rgba(212,175,55,0.18)` 仅用于"当前选中/主推"卡片 |
| 内边距 | 16px（`spacing4`），卡片间距 12px |

### 3.3 导航栏

- 小程序：`navigationBarBackgroundColor: #08080A`、`navigationBarTextStyle: white`（`app.config.ts` 已配置，保持），标题文字实际渲染为暖白。
- H5：自绘导航栏底色 `--mall-nav-bg`，底部 1px `var(--mall-border-light)` 分隔线；标题 17px/600 暖白。
- 导航栏右侧功能图标（铃铛/消息）默认 `--mall-text-secondary`，有未读时铃铛描金 + 金色圆点角标。
- 沉浸式页面（首页 Hero 顶到状态栏）：导航栏透明 → 滚动超过 Hero 后渐变为 `#08080A`，H5 与小程序使用同一滚动阈值（80px）。

### 3.4 列表布局

- 列表项背景与页面底色一致（不卡片化），项间用 1px `var(--mall-border-light)` 分隔线，左缩进 16px 对齐文字基线。
- 列表项按压态：背景变 `--mall-surface-2`（不用透明度变化，小程序上更稳）。
- 商品卡列表：左图（1:1，圆角 8px，金色细边框 `rgba(212,175,55,0.14)`）+ 右侧标题（暖白 15px/500，2 行截断）+ 价格（亮金 #F0C86A，17px/600，¥符号 12px）+ 辅助信息（三级灰 12px）。
- 空状态：深底上不使用纯白插画，用 80px 线性图标（`--mall-text-tertiary`）+ 暖灰文案 + 金色描边按钮引导。

## 四、图标优化规范

现有实现为 **SVG mask 线性图标**（`components/Icon.tsx`，仅 alpha 通道参与渲染，颜色完全由父级 `color` 控制）——这正好满足黑金主题「换色零资源」的要求，继续沿用并补充以下规范：

### 4.1 视觉风格

- 统一 24×24 viewBox，stroke-width 1.8，圆角端点（round cap/join），线性（stroke）风格，**不混用面性图标**。
- 尺寸阶梯：功能入口 24px、列表辅助 18px、导航/操作 22px、标签栏 22px。

### 4.2 着色规则

| 场景 | 默认态 | 选中/激活态 | 禁用态 |
| --- | --- | --- | --- |
| 底部标签栏图标 | `--mall-text-tertiary` #7C7466 | `--mall-primary` #D4AF37（图标+文字同步变金） | — |
| 页面功能图标 | `--mall-text-secondary` #B3A995 | 金色或金色弱底圆（40px，`rgba(212,175,55,0.14)` 底 + 金图标） | `--mall-text-tertiary` 50% 透明度 |
| 警示类图标 | 对应功能色（成功绿/警告橙/危险红） | — | — |

### 4.3 底部标签栏（AppTabbar）

- 栏体：背景 `#0D0C10`（略高于页面底色，建议新增令牌 `--mall-tabbar-bg`），顶部 1px 金线分隔 `rgba(212,175,55,0.18)`，高度 50px + 安全区。
- 选中态：图标金色描边等效加粗（stroke-width 视觉从 1.8 → 2.2 的效果，用颜色对比即可，不必换 path），图标上方可选 3px 金色小横条作为选中指示。
- 文字标签：默认 10px 三级灰；选中 10px 金色 600。
- 购物车角标：金底（#D4AF37）+ 深色数字（#14110A），10px 圆角胶囊，位置右上偏移 2px。

### 4.4 功能性图标清单对照

现有 25 枚图标（home/shop/cart/bell/user/wallet/users/report/chart/palette/book/upload/edit/card/box/packageCheck/checkCircle/headset/userPlus/star/search/horn/message/info/check）已覆盖主要场景；需补充：`filter`（筛选）、`location`（地址）、`phone`（客服电话）、`qrcode`（推广码）、`arrowRight`（列表箭头，替代字符 `>` 保证双端渲染一致）。

## 五、按钮优化规范

### 5.1 按钮类型与样式

**主按钮（Primary）— 金色渐变填充**

| 属性 | 值 |
| --- | --- |
| 背景 | `linear-gradient(135deg,#E3C173 0%,#D4AF37 45%,#B8952B 100%)` |
| 文字 | `#14110A`，16px/600 |
| 圆角 | 999px 全圆角（移动端 CTA 建议）或 8px（表单内） |
| 高度 | 大 48px / 中 40px / 小 32px |
| 按压态 | 渐变整体压暗：滤镜 `brightness(0.88)` 或切换到 `#B8952B` 纯色 |
| 禁用态 | 背景 `rgba(212,175,55,0.18)`，文字 `rgba(244,239,228,0.35)`，去掉渐变 |

**主按钮变体（描金版）— 金色描边黑底**：用于与填充金按钮同屏出现时的次核心操作，避免"双金抢戏"。1px 金描边 `var(--mall-primary)` + 金色文字 + 透明黑底；按压时底色变 `rgba(212,175,55,0.14)`。

**次级按钮（Secondary）**：`--mall-surface-2` 底 + 1px `--mall-border` 边框 + 暖白文字；按压变 `--mall-surface-3`。

**文字按钮（Text）**：金色文字（#D4AF37），按压时透明度 0.6；用于"查看更多""编辑"等弱操作。

**危险按钮**：保持红色系语义（`--mall-danger` 描边/文字），**不得镀金**——危险操作必须一眼可辨。

### 5.2 状态总表

| 状态 | 主按钮 | 描金按钮 | 次级按钮 |
| --- | --- | --- | --- |
| 默认 | 金色渐变 + 深字 | 金框金字黑底 | 深灰底暖白字 |
| 按压（active） | brightness(0.88)，缩放 0.98 | 底 rgba(212,175,55,0.14) | 底 #242028 |
| 禁用 | 金 18% 底 + 35% 白字，无渐变 | 边框/文字降为 `--mall-text-tertiary` | 文字降为三级灰 |
| 加载 | 金色 spinner（深底上）/ 深色 spinner（金底上），宽度锁定防跳动 | 同左 | 同左 |

### 5.3 触控与尺寸规范（移动端）

- 可点区域 ≥ **44×44px（88×88rpx）**：视觉尺寸不足时用透明 padding 补足热区（标签栏图标视觉 22px，热区 48px）。
- 底部固定 CTA（如"立即采购"）：高度 48px，左右边距 16px，底部预留 `env(safe-area-inset-bottom)` 安全区 + 8px。
- 相邻按钮间距 ≥ 12px；一行最多 1 个填充金按钮。
- H5 hover 态：主按钮渐变亮端上移（`background-position` 过渡 200ms），描金按钮底淡入 `rgba(212,175,55,0.08)`。

## 六、双端一致性策略

1. **单一来源**：所有色值/字号/间距只维护在 `packages/shared/src/tokens.ts` 的 `themePacks.gold.vars`，mini-b 的 `app.scss` `.theme-gold` 块与其逐项同步（现有机制，继续保持），新增令牌需同步两处 + 本规范文档。
2. **页面零硬编码**：样式只写 `var(--mall-*)`，代码评审时 grep 拦截十六进制色值。
3. **环境差异收敛在适配层**：
   - H5：`html/body` 挂主题 class + 背景（NutUI 弹层 Portal 到 body 需继承变量，已实现）；
   - 小程序：`Taro.setNavigationBarColor` 同步导航栏、`setBackgroundColor` 同步窗口底色（已实现）。
4. **组件库**：NutUI 组件通过 `--nutui-*` 变量映射接管（`NUTUI_THEME_VAR_MAP`），黑金模式下需确认 `--nutui-color-primary` 等已指向金色系；弹窗/ActionSheet/Toast 等 Portal 组件需在 H5 上验证变量穿透。
5. **图标/插画**：SVG mask 方案天然双端一致；位图资源（如 Banner）输出 2x/3x 两套并按 DPR 加载。

## 七、对比度与可读性校验（附录 A）

| 组合 | 对比度 | WCAG 结论 |
| --- | --- | --- |
| 暖白 #F4EFE4 / 底 #08080A | ≈17.0:1 | AAA ✅ |
| 金 #D4AF37 / 底 #08080A | ≈9.4:1 | AAA ✅ |
| 亮金价格 #F0C86A / 卡片 #141217 | ≈10.5:1 | AAA ✅ |
| 浅灰正文 #B3A995 / 底 #08080A | ≈8.6:1 | AAA ✅ |
| 中灰辅助 #7C7466 / 底 #08080A | ≈4.3:1 | AA（限大字号/非关键信息）⚠️ |
| 深字 #14110A / 金底 #D4AF37 | ≈9.1:1 | AAA ✅ |
| 金线 rgba(212,175,55,0.14) / 卡片 | — | 装饰用途，不承载信息 ✅ |

⚠️ 注意事项：
- 三级灰 #7C7466 不得用于 12px 以下的关键信息（如库存紧张提示），此类信息用二级灰或警告橙。
- 金色文字下方垫图片/渐变时，必须保证文字落点区域实测亮度仍满足 4.5:1（Hero 区标题建议加 0.3 透明度深色蒙层或 1px 深色 text-shadow）。
- 金色描边（1px）仅作装饰，不替代选中态的颜色变化。

## 八、屏幕适配规范

- 尺寸单位统一 **rpx**（设计基准 750）；文字在 H5 端按 `transform: scale` 以外的 Taro 默认换算即可，关键标题可锁定 px 防过大。
- 安全区：底部栏/CTA 使用 `constant(safe-area-inset-bottom)` + `env(safe-area-inset-bottom)` 双写兼容；iPhone 刘海屏顶部 Hero 区预留状态栏高度。
- 响应式断点（H5 后台/平板场景）：≥768px 时商品列表从 2 列变 3–4 列，卡片最大宽度 400px 居中；≥1024px 时页面内容区限宽 750px 居中，两侧露出深黑底。
- 深色模式图片：商品图/Banner 在 H5 端建议 `border: 1px solid var(--mall-border-light)` 防止浅色图"闪边"；避免使用纯白底图片，必要时装进 `#141217` 底卡内。
