# 百英诺商城分销系统 · 腾讯云云托管部署包（SQLite）

一个容器内同时提供：

- 平台后台前端：`/`
- 商家端 H5：`/b/`
- 客户端 H5：`/c/`
- 后端 API：`/api`
- 商品图片：`/uploads`
- 健康检查：`/api/health`

默认使用 SQLite，首次启动自动从镜像内置的演示库复制到 `DATA_DIR/mall.db`。

## 部署步骤（腾讯云云托管）

1. 新建/进入服务（如 `baiyingnuo-service`）→「部署发布」→ 选择「手动上传代码包」→ 上传本 zip。
2. 端口填写 **80**，与容器监听端口一致。
3. 建议在「服务设置 → 环境变量」配置：
   - `JWT_SECRET`：固定一个长随机字符串（不配置会生成临时密钥，重启后登录态失效）。
   - `DATA_DIR`：默认 `/data`；如需持久化，请挂载 CFS/云存储到该目录，或把 `DATA_DIR` 改到挂载路径。
4. 点击「发布」。首次构建会安装依赖并编译三端，耗时较长属正常。

## 数据持久化

- 默认库路径：`/data/mall.db`。
- **未挂载持久化存储时**，容器重启/重新发布后会重新复制预置演示库，期间产生的业务数据会丢失。
- 需要保留数据：在云托管挂载 CFS 到 `/data`；或设置 `DATA_DIR=/你的挂载目录`。
- 重置演示数据：设置 `RESET_DB=1` 后重启一次（会覆盖现有 SQLite 文件）。

## 本地验证

```bash
docker build -t baiyingnuo-cloudbase .
docker run --rm -p 8080:80 \
  -e JWT_SECRET=local-test-secret \
  -v "$(pwd)/data:/data" \
  baiyingnuo-cloudbase
# 打开 http://localhost:8080
```

## 说明

- 本镜像固定为 **SQLite 构建**。之后再切腾讯云 MySQL/PostgreSQL，需要把 `DATABASE_URL` 指向对应数据库并重新构建镜像（Prisma Client 是按方言生成的）。
- 上传的商品图片存于容器内 `/uploads`，重新发布会被镜像内的演示图覆盖；生产建议切换 COS/CDN。
- 后台前端已内置在镜像中，无需单独部署静态站点。
